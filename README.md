# Bon Art Optiek — website make-over

Prototype voor de make-over van bonartoptiek.nl (Almere Poort).

- `v1/` — originele levering van de developer, ongewijzigd bewaard.
- `v2/` — gecorrigeerde versie: origineel logo, kleurpalet afgeleid uit het
  logo (#231f20 / #f7931d), herschreven teksten, blokken voor gezinnen,
  senioren en doorverwezen patiënten, sectie voor verwijzers, en geen externe
  afhankelijkheden (lettertype lokaal, Jost, OFL-1.1).

Open `v2/index.html` in de browser. Geel gemarkeerde tekst in de pagina is een
plaatshouder die nog ingevuld moet worden (naam eigenaar, talen, AGB-code,
KvK-nummer, privacyverklaring).
